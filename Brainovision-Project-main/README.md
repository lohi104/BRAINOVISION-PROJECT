# 📚 LearnovaX AI - Smart AI Learning Assistant

## 🚀 Overview

LearnovaX AI is an AI-powered learning platform designed to provide students with a personalized, interactive, and engaging learning experience. It acts as a 24/7 virtual tutor by helping students understand concepts, resolve doubts instantly, prepare for exams, and collaborate with peers.

The platform combines Artificial Intelligence with modern web technologies to make learning smarter, faster, and more effective.
